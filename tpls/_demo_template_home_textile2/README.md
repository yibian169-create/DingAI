# 棉叙 LINEN NARRATIVE · 家纺工厂模板

全新布局的家纺工厂首页模板，视觉语言为「奶油白 + 亚麻 + 鼠尾草绿 + 陶土橙」的编辑型家居杂志风，与系统默认工业风完全不同。

## 包含的全新首页模块

| 模块 key | 说明 |
| --- | --- |
| board | 布料拼贴 Hero：不对称分栏 + 3 张悬浮图卡 + 圆形材质徽章 |
| collections | 空间系列：卧室 / 浴室 / 客厅 / 儿童房 / 酒店 横向滑动 |
| story | 材质故事：左右交替分屏 + 数字 |
| timeline | 制造流程：四道工序竖排时间线 |
| quote | 工艺引语：大衬线居中标题 |
| （复用）ticker / stats / products / cta | 面料跑马灯 / 深色数字带 / 产品网格 / 底部卡片，已重样式匹配 |

> 注：board / collections / story / timeline / quote 为系统新增的首页模块（核心 tpl/home/ 已扩展）。本模板 zip 仅含换肤资源；新模块文件需随核心一同部署（已在当前 deyingding 工程内置）。

## 导入并启用

1. 后台 → 模板中心 → 导入模板 → 选择 `home_textile2.zip` → 上传导入
2. 启用该模板
3. 进入「首页 DIY」→ 右上角「粘贴 home.json」→ 粘贴本包内的 `home.json` 内容 → 保存
4. 前台刷新即可看到完整家纺首页

## DIY 可视化编辑

- 后台左侧组件库已新增 5 个模块（🧵 布料拼贴 / 🛋️ 空间系列 / 🌿 材质故事 / 🪡 制造流程 / 💬 工艺引语），可拖拽排序、显隐。
- 基础字段（标题 / 副标题 / 按钮 / 引语等）在右侧属性面板直接改。
- 空间卡片、材质分屏、流程条目等数组内容，通过「粘贴 home.json」整体写入。
- 图片：本包 `home.json` 已内嵌离线 SVG 图；正式使用时，把图片上传到「图片空间」后，替换 home.json 中对应 `img` 字段为图片地址即可。

## 文件结构

```
style.css      # 全新布局样式 + 系统区块重样式
main.js        # 滚动浮现 / 数字递增 / 分屏视差 / 顶栏换标
home.json      # 首页布局 + 全部内容（含内嵌图）
README.md
images/        # 16 张 SVG 占位图（与 home.json 内嵌图一致，供参考）
```
