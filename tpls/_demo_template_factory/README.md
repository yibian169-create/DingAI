# 家纺工厂模板 · 奶油白鼠尾草绿（清新版 v5）

家纺 / 纺织 / 布艺 / 床品工厂专用。深色高级感 + **Hero 大图轮播** + 拉满的动效。

## 🖼 Hero 轮播（炫耀设备与产品）

这是本版最大亮点：**首页首屏多图轮播**，用来放厂房实拍 / 设备照片 / 产品大图。

配置方式（**导入模板后依然可编辑**）：
1. 后台「模板中心 → 首页 DIY」
2. 点「首屏 Hero」组件 → 右下角「⚙ 高级属性」展开
3. 填「**轮播图片**」：每行一个图片地址，几张图就自动轮播几张
4. 填「轮播间隔（秒）」：默认 5

> 图片地址怎么来：先在「图片空间」上传图片 → 复制图片地址 → 粘贴进来即可。

## 动效清单

1. **Hero 大图轮播** —— 多图自动切换（默认 5 秒），带缓入缩放（Ken Burns）效果 + 金色指示点
2. **丝线飘动画布** —— 90 条金色丝线缓慢漂浮（家纺主题：线）
3. **主标题逐字浮现** —— 每个字旋转入场
4. **滚动视差** —— Hero 内容随滚动上移淡出
5. **金线流光** —— 标题/数字/CTA 金线持续流动
6. **按钮光晕脉冲** —— 金色按钮呼吸
7. **背景光晕呼吸** —— 右上金色光晕 7s 循环
8. **能力卡 3D 倾斜** —— 跟随鼠标透视旋转
9. **数字递增** —— 1.5s 缓动
